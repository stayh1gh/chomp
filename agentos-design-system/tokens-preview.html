Chomp Dashboard — Design Tokens

Generated from primitive-tokens.md + semantic-tokens.md. This system is dark-only — every swatch below renders its actual resolved value from tokens.css, no separate light mode to compare. Two token pairs (badge status text, the Approve label, and ink-faint) were adjusted from their raw Figma-sampled hex during generation because the sampled value failed WCAG AA contrast — see the "a11y-corrected" note on each affected swatch below.

1. Color Tokens

Brand & Status
brand
→ indigo.500
Primary CTA, FAB, Done badge/ring, avatar chip, focus ring. Never decorative.
success
→ green.500
Running status only. Never a generic "good" indicator.
warning
→ orange.500
Waiting for User status only.
danger
→ red.500
Waiting for Approval status, error toast/status text.
approve
→ approve.approve-text-a11y (a11y-corrected)
Approve action label. Sampled #338225 failed 4.5:1 (3.61:1) — corrected to 5.14:1.
Surfaces
canvas
→ surface.surface-0
Page-level background. Never inside a card or panel.
surface
→ surface.surface-1
The single app panel. Not for cards.
surface-card
→ surface.surface-2
Cards, setting rows, outline badge fill, file chips.
surface-inset
→ surface.surface-3
One nesting level inside a card. Today: description well only.
accent-tile
→ surface.surface-accent-tile
Brand-mark tile background. Not a control surface.
Borders & Dividers
border
→ surface.surface-border
Default hairline: panel edge, dialog edge, topbar/side-section rules.
border-strong
→ surface.surface-border-strong
Badge outline, select/input border, file-chip border.
border-hover
→ component-flat.border-hover
Hover state of border-strong on select/file-chip.
divider
→ surface.surface-divider
Card footer rule above Approve. Never a general-purpose divider.
Text (ink-*)
ink
→ text.text-0
Highest-emphasis single line: card title, dialog title.
ink-strong
→ text.text-1
Panel/column headers; default body color.
ink-body
→ text.text-3
Multi-line description and prompt text.
ink-muted
→ text.text-4
Card meta, outline-badge text, settings hints.
ink-subtle
→ text.text-5
Column count, header icon buttons, side-section labels.
ink-nav
→ text.text-6
Sidebar nav label (inactive).
ink-faint
→ text.text-7-a11y (a11y-corrected)
Lowest-emphasis utility text. Sampled #6b6b6e failed 4.5:1 (3.75:1) — corrected to 4.78:1.
ink-disabled
→ text.text-8
Placeholder/disabled only — exempt from 4.5:1 (WCAG inactive-control exemption).
ink-inverse
→ text.text-0
Text on the brand fill only — passes 4.5:1 there, fails on status fills.
ink-on-status
→ text.ink-on-status-fill
Text on success/warning/danger badge fills. White fails there — this clears 6–9:1.
